# Beginner questionnaire

Ask one unanswered question per message and accept a free-form answer. Do not show answer options except in **Fidelity**.

## Scope

Ask: “What would you like to reconstruct: a single room, an apartment, a house, or another space?”

If the user is unsure, recommend one room as a fast proof.

## References

Ask: “Do you already have photographs or video of the space?”

If yes, immediately ask: “Please attach them here or provide the folder where they are stored.”

If references still need to be captured, give only this checklist:

- photograph the opposite corner from every corner;
- photograph doors, windows, stairs, and room transitions separately;
- include floor and ceiling in several frames;
- avoid digital zoom and filters;
- include one known measurement if possible.

## Measurements

Ask: “Do you have a floor plan or at least one known measurement, such as ceiling height or door width?”

If not, continue with a visual approximation and ask later only for the most useful anchor measurement.

## Desired result

Ask: “What would you like to receive at the end? Describe it in your own words — for example, a walkthrough, still images, video, or all of them.”

## Fidelity

Ask only if intent is not already clear:

> What matters most?
>
> 1. Reproduce the photographed room as closely as possible
> 2. Preserve the layout but improve the interior
> 3. Reproduce only a similar atmosphere
> 4. I do not know — choose the best option

## Rights and privacy

Ask: “Are these your photographs, or do you have permission to use them? May the result be published, or must everything remain local?”

## Confirmation

Before building, summarize in no more than six lines:

```text
Scope: entire house
References: 42 photographs and a first-floor plan
Output: walkthrough and selected renders
Accuracy: plan- and photo-assisted
Privacy: local only
First review: rough layout
```

Do not ask the user to repeat the brief.
